# Manual humano de Qwen Voice Lab

- [`Qwen_Voice_Lab_Manual_de_Uso_ES.pdf`](Qwen_Voice_Lab_Manual_de_Uso_ES.pdf): edición humana lista para lectura o impresión.
- [`guide.html`](guide.html): fuente editable del PDF.
