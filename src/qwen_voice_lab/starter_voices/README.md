# Bundled starter voices

The audio files in this directory are original synthetic outputs intentionally distributed with the product. They contain no recording or clone of a human speaker.

`amara_sol/reference.wav` was generated with `Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign` from the instruction and carrier text recorded in `voice.json`. Its SHA-256 is verified before it is copied into a new local catalog.

The bundled audio and its voice metadata are released under CC0 1.0: https://creativecommons.org/publicdomain/zero/1.0/
